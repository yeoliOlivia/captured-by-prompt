# COCO128 photos

128 original JPEG images from the Ultralytics COCO128 release:
https://github.com/ultralytics/assets/releases/download/v0.0.0/coco128.zip

Dataset documentation: https://docs.ultralytics.com/datasets/detect/coco128/
Original COCO terms and image attribution: https://cocodataset.org/#termsofuse

Only images are imported into search; no class labels or captions are used. Original COCO numeric filenames are preserved.
